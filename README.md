# exerciciosDeLogicadeProgramacaoManzano
Resolução prática e estruturada das páginas de exercícios (pág. 25, 41, 46, 50 e 66) do livro "Estudo Dirigido: Algoritmos" (Manzano, 2000). Algoritmos codificados em VisuAlg (Português Estruturado) cobrindo estruturas sequenciais, condicionais e laços de repetição.
